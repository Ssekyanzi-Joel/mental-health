MIND AWARE APPLICATION - CODE STRUCTURE DOCUMENTATION
================================================================

PROJECT OVERVIEW
================
Name: mind_aware_application
Description: A comprehensive mental health and wellness Flutter application
Version: 1.0.0+1
Flutter SDK: ^3.9.0

PURPOSE
=======
Mind Aware is a digital mental health platform that provides:
- Professional therapy services and booking system
- AI-powered mental health assistant
- Community support network
- Digital journaling and mood tracking
- Mental health resources and education
- Multi-language support (English, Luganda, Nyankole)

ARCHITECTURE PATTERNS
=====================

1. MODULAR ARCHITECTURE
- Separation by user roles (Admin, Therapist, User)
- Feature-based organization
- Reusable components and widgets

2. STATE MANAGEMENT
- Provider pattern for state management
- Centralized state for language preferences
- Local state for UI components

3. NAVIGATION STRUCTURE
- Bottom navigation with drawer
- Role-based navigation shells
- Hierarchical page organization

4. DATA LAYER
- Firebase backend integration
- Model classes for data structures
- Service layer for API interactions

5. PRESENTATION LAYER
- Screen-specific components
- Reusable UI widgets
- Custom app bars per user type
